AK Nails & Spa website source

Includes HTML pages, styles.css, app.js, favicon and image assets.
Run a local server from this folder: python3 -m http.server 8000
Then open http://localhost:8000
Upload the contents of this folder to a static hosting web root.
Navigation and assets use relative paths; works from a domain root or a subpath (e.g. GitHub Pages).
Book Now links to RICH; this package does not include RICH code or customer data.
Fonts load from Google Fonts and require internet access.
